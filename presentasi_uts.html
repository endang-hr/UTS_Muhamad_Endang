Tentang Usaha Endang Microtech

Endang Microtech adalah usaha mikro di bidang jasa teknologi dan reparasi perangkat digital yang berlokasi di Kp. Gardu, Ds. Majasari, Kec. Jawilan, Kab. Serang, Banten. Usaha ini melayani kebutuhan masyarakat sekitar maupun pelaku UMKM dalam servis laptop/PC, instalasi ulang sistem operasi Windows & Linux, perakitan komputer spek kerja/gaming, instalasi jaringan WiFi/LAN, servis printer, pasang CCTV, hingga pembuatan website bisnis.

🎯 Tujuan Pembangunan Website

Membangun profil digital terpercaya, menghadirkan transparansi harga melalui tabel bergaris, dan menyediakan saluran komunikasi cepat via WhatsApp dan Form Konsultasi.

📂 Arsitektur Multi-Page (3 Halaman)

1. index.html : Beranda, banner hero visual & profil keunggulan.
2. layanan.html : Katalog servis & Tabel Estimasi Biaya/Garansi.
3. kontak.html : Alamat resmi, peta lokasi & form pesan.

BAGIAN 2: TAG HTML YANG DIGUNAKAN
Tag Dasar, HTML5 Semantic, Tabel & Form
SLIDE 02

2 Analisis Tag HTML yang Digunakan

Kategori Tag Tag yang Digunakan Fungsi & Penerapan pada Proyek
1. Struktur Dasar <!DOCTYPE html> <html> <head> <meta> <title> <body> Fondasi standar HTML5, viewport layar mobile responsif, judul tab browser, serta pembungkus konten utama.
2. HTML5 Semantic <header> <nav> <main> <section> <article> <footer> Memberikan struktur logis yang bermakna bagi browser & SEO. Memisahkan header, nav, section, artikel mandiri, dan footer.
3. Heading & Konten <h1> s/d <h4> <p> <strong> <span> <ul> <li> Hirarki judul tertata rapi (<h1> nama brand, <h2> judul section), paragraf deskripsi, teks tebal penekanan, dan list fitur.
4. Multimedia & Link <img> <a href="..."> Menampilkan logo dan foto banner dari folder images/, serta navigasi hyperlink antarhalaman dan direct chat WhatsApp.
5. Tabel Terstruktur <table> <thead> <tbody> <tfoot> <tr> <th> <td> Membangun tabel daftar harga service, estimasi durasi, dan garansi secara rapi sesuai instruksi tugas UTS.
6. Form Interaktif <form> <input> <select> <textarea> <button> Digunakan pada kontak.html untuk sarana pesan konsultasi online calon pelanggan.

BAGIAN 3: METODE STYLING WEBSITE
Vanilla CSS, CSS Grid, Flexbox, Variables & Aesthetics
SLIDE 03

3 Bagaimana Saya Memberikan Styling

🎨 1. External CSS & CSS Variables

Dikelola terpusat di style.css. Memanfaatkan :root untuk warna konsisten:

:root {
  --bg-primary: #0b1329; --accent-cyan: #38bdf8;
  --accent-blue: #2563eb;
}

📐 2. Layouting: Flexbox & CSS Grid

Flexbox untuk meratakan navbar & tombol CTA. CSS Grid untuk kartu layanan (3 kolom) & footer:

.services-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
}

✨ 3. Efek Modern & Glassmorphism

Efek kaca buram transparan pada navbar & kartu hero:

.hero-card {
  background: rgba(255, 255, 255, 0.06);
  backdrop-filter: blur(14px);
}

📊 4. Styling Tabel & Zebra Striping

Tabel bergaris profesional dengan pewarnaan selang-seling:

table { border-collapse: collapse; }
tbody tr:nth-child(even) {
  background-color: #f8fafc;
}

📱 5. Responsive Web Design (Media Queries)

Menggunakan @media (max-width: 768px) dan @media (max-width: 480px) agar tata letak berpindah otomatis menjadi tata letak vertikal yang nyaman di smartphone Android maupun iPhone.

🎤 Naskah Presentasi (Penjelasan Styling CSS)

"Terkait styling, saya menggunakan Vanilla CSS eksternal di file style.css tanpa framework pihak ketiga untuk membuktikan penguasaan CSS murni.

Saya menerapkan CSS Custom Properties (:root) untuk tema warna modern, memadukan Flexbox pada navigasi dan CSS Grid pada kartu layanan dan footer. Saya juga menyematkan efek modern seperti Glassmorphism, zebra striping pada tabel harga, serta Media Queries agar tampilan web 100% responsif di layar ponsel maupun laptop."
